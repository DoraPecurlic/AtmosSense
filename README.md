A modular embedded environmental monitoring system that combines STM32 firmware, local sensor visualization, serial telemetry, MQTT messaging, PostgreSQL storage, Grafana dashboards and machine-learning-based event detection.

The STM32 collects environmental and optical measurements from BME688 and APDS-9960 sensors, displays live readings on an SSD1306 OLED and transmits structured telemetry over UART. A Python gateway validates the serial data, stores a local CSV copy and publishes each reading to MQTT. A containerized consumer then writes the measurements to PostgreSQL for visualization in Grafana.

A machine-learning extension is currently being developed to detect unusual air-condition changes and classify light conditions from labeled sensor sessions.

## Features

### Embedded Environmental Monitoring

- Temperature, relative humidity, atmospheric pressure and gas resistance measurements using the BME688
- Clear, red, green and blue light channels plus proximity measurements using the APDS-9960
- Shared I2C bus for both sensors and the OLED display
- Periodic acquisition and telemetry transmission from the STM32 main loop

### Local OLED Interface

- Startup screen for the AtmosSense Edge device
- Environment page showing temperature, humidity, pressure and gas resistance
- Light page showing clear, RGB and proximity values
- Navigation between pages through the NUCLEO user button

### Telemetry and Data Pipeline

- Structured application-layer UART message generated by the firmware
- Python parsing and numeric validation of every telemetry field
- Local CSV storage with timestamps
- MQTT publishing 
- Dedicated MQTT consumer for PostgreSQL 

### Infrastructure and Visualization

- Docker Compose environment containing:
  - Eclipse Mosquitto
  - PostgreSQL
  - Grafana
  - Python database consumer
- Automatic PostgreSQL table and index creation
- Persistent Docker volumes for broker, database and dashboard data
- Grafana dashboard definition included in the repository

### Machine Learning — In Progress

- Command-line collector for labeled air and light sessions
- Air labels: `normal`, `perfume`, `alcohol` and `heat`
- Light labels: `dark`, `daylight` and `artificial`
- Filtering based on BME688 gas-valid and heater-stable flags
- Overlapping time windows of 20 samples with a step of 5 samples
- Isolation Forest pipeline trained on normal air sessions

The air model detects whether a measurement window differs from learned normal conditions. It does not identify a particular gas or classify the exact source of an event.

## Software Architecture

### STM32 Firmware

| Module | Responsibility |
| --- | --- |
| `bme688_sensor` | Adapts the Bosch BME68x driver to STM32 HAL and provides compensated environmental readings |
| `apds9960` | Configures the optical sensor and reads clear, RGB and proximity data |
| `display_view` | Renders the startup, environment and light pages on the OLED |
| `serial_telemetry` | Encodes readings into the UART telemetry format and maintains the sequence number |
| `main.c` | Initializes hardware, coordinates acquisition, changes display pages and transmits readings |
| SSD1306 driver | Controls the OLED framebuffer and I2C communication |

### Python Application

| Component | Responsibility |
| --- | --- |
| `SerialConnection` | Owns the PySerial connection and receives complete UART lines |
| `SerialProtocol` | Validates and converts telemetry messages into `SensorReading` objects |
| `CsvStorage` | Appends readings to a local CSV file |
| `MqttPublisher` | Serializes readings as JSON and publishes them to MQTT |
| `DatabaseConsumer` | Subscribes to telemetry and recreates typed sensor readings |
| `DatabaseStorage` | Persists readings in PostgreSQL |
| `MLDataCollector` | Records labeled MQTT sessions for model development |
| `air_features` | Cleans sensor data and creates window-based air features |
| `train_air_model` | Trains and serializes the air anomaly-detection pipeline |
| `evaluate_air_model` | Evaluates the model on sessions excluded from training |


## Hardware

- STM32 NUCLEO-F401RE development board
- BME688 environmental sensor
- APDS-9960 RGB, ambient light and proximity sensor
- SSD1306 0.96-inch OLED
- Qwiic cables and jumper wires
